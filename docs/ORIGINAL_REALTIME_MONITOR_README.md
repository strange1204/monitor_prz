## ⚙️ 監控邏輯與雙重觸發條件

本系統每隔 **60 秒** 自動抓取台指期即時點位，結合【Mode 3 雙演算法優點融合模式】計算 PRZ 價位與交易建議。

只有當滿足以下**兩大雙重條件**時，才會自動觸發 Gmail 電子郵件寄送：

1. **條件一（高信心水準）**：當前計算出之進場建議為 **`信心水準：高`**（例如價格進入多重 PRZ 超級共振區防線）。
2. **條件二（防重複發送）**：當前訊號之特徵碼（方向 + 進場區間 + 理由 + 點位）**與前一次成功發送之 Email 內容不同**。

## ☁️ GitHub Actions 雲端 24/7 高頻自動監控部署 (`auto_monitor.yml`)
