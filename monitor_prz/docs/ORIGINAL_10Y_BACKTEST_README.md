## 🛡️ 3 次失敗中斷保護機制 (3-Strike Rule Guard)

程式內建獨立的 `StepErrorTracker` 類別：
- 追蹤「數據下載」、「轉折點過濾」、「PRZ價位計算」、「交易模擬」四大階段。
- **保護原則**：若任何單一步驟失敗或資料缺漏累積達 **3 次**，系統會拋出 `StepBottleneckException` **立即安全中斷執行**，印出最近 3 次錯誤細節，並主動提示與使用者討論後再繼續。
